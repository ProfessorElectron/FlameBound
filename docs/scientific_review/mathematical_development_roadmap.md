## Recommended next implementation slice

The typed deterministic calculation contract, explicit binary-diluent verification, provenance envelope, and core unit/edge tests are now implemented. Next, add Pydantic request/response schemas and backend routes that preserve the same input validation and provenance. Then add repository-level evidence coverage that only counts source inventory and verification statuses. Do not calculate empirical similarity until verified points exist.

## Deferred formulations

Do not add a generalized dimensionless pipeline before defining each target question and property source. Do not implement lunar-gravity interpolation, a universal flame-spread boundary, or a probability from Gower distance. No correlation should combine oxygen mole fraction and pO2 as unrelated predictors by default.
